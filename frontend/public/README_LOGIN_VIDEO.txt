Background video for the midnight login page
============================================

Place one or both files in this folder (frontend/public/):

  login-bg.mp4   (H.264, muted loop-friendly, 1920×1080 recommended)
  login-bg.webm  (optional WebM fallback)

Suggested content: slow cinematic legal atmosphere (courtroom abstract,
constitution texture, amber light beams). Keep file size under ~8MB for fast load.

If no video is present, the page automatically uses an animated midnight gradient fallback.
